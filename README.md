# 练吧 · 本地自学工作台

面向跨专业初学者的本地自学工作台，内置三个子工作台。日均学习 2h 设计，数据全部保存在本地。

- **工作台 1 · 信息系统高项**：依据软考高级《信息系统项目管理师教程（第4版）》目录整理 24 章考纲，按**弹性节奏**生成学习计划（工作日约 45 分钟、周末约 2 小时，压力自动分散），计划**一周一屏**翻看（连续空档/计划开始前自动折叠成一行），可打卡，一键跳转 B站/YouTube 公开课与「软考达人」等刷题入口。
- **工作台 2 · AIIA · AI 应用求职雷达**：面向 AI 应用岗（LLM 应用开发 / AI Agent 开发 / AI 产品经理 / AI 解决方案架构师），把一周新闻、一月热点按**求职方向筛选并打标签**，每个方向配对应学习入口；资讯可一键延伸成「学习小卡片」。
- **工作台 3 · 健康猿（居家版）**：以**居家减脂塑形 + 适度增肌**为目标（全程低冲击、不安排跑跳，关节友好）。用 瑜伽垫 / 瑜伽球 / 瑜伽砖 / 哑铃（4–6kg）/ 弹力带 / 泡沫轴 编排训练 —— 每次含**热身 + 主训练 + 拉伸**，动作带**简笔示意 + 组次 + 要点**；按 **4 周渐进**循环（适应 → 累积 → 强化 → 减载）自动调整组数与离心速度。**只给「每周 N 次」的训练建议、不限定周几**，实际练了哪套由你在日历上**主动选填打卡**（也可补记/撤销，轻量日单独标记）。**不做卡路里监控**，另配「今日餐饮」（只做**早 / 晚**两餐，减脂 + 消炎思路，含**周末 30 分钟备菜清单**，主料精简可复用）。教学来源分层：**国家体育总局居家健身（官方优先）→ B站按收藏量排序 → 无跑跳跟练合集**。

## 启动方式

双击项目根目录下的 **`启动练吧.bat`**，浏览器会自动打开：

```
http://127.0.0.1:8848/
```

> 首次启动会稍慢（要等内置 Node 运行时加载）。关闭命令行窗口即停止服务。
> 内置了便携版 Node.js（`.runtime/`），**无需单独安装 Node，也无需管理员权限**。

命令行方式（可选）：

```bat
.runtime\node-v24.20.0-win-x64\node.exe server.js
```

更换端口：`set PORT=9000 && .runtime\...\node.exe server.js`

## 分享给别人

**方式 A · 临时公网链接（最快）**
双击 **`分享练吧.bat`**，等约 10 秒，窗口里会出现一行
`https://xxxx-xxxx-xxxx.trycloudflare.com` —— 把这个链接发出去即可。
- 特点：无需注册、免管理员；**你的电脑和这个窗口必须一直开着**，关闭即失效，重启会换新链接。
- 🔐 **访问密码**：没有任何默认密码。首次运行会自动生成一个随机密码，保存在 `data/share-password.txt`，同时在服务窗口打印出来；想改成自己的（例如 `1287`）直接编辑该文件即可。
  - 本机 `127.0.0.1` 打开**免密**；公网链接需先输入密码，验证后同一浏览器 30 天内免再输。
  - 也可用环境变量覆盖（优先级最高）：`set LIANBA_PASSWORD=你的密码` 后再启动。
- 侧栏右下角会多出「🚪 退出」按钮，可清除登录状态。

**方式 B · 离线包（发给别人自己跑）**
把 `练吧-离线包.zip` 发给对方，解压后双击 `启动练吧.bat` 即可，**无需安装 Node**。
每个人的数据各自保存在自己电脑的 `data/state.json`，互不干扰。

**方式 C · 自己部署成长期链接（进阶）**
把 `public/` 当作静态站点托管到任意静态平台即可打开界面；若还想用资讯聚合与本地存盘，需要一个能跑 Node 的环境（直接部署整个项目目录、启动 `server.js`）。

## 目录结构

```
练吧/
├─ 启动练吧.bat          # 一键启动
├─ server.js             # 本地服务：静态页面 + 状态存储 + RSS 资讯聚合（零依赖）
├─ package.json
├─ public/
│  ├─ index.html
│  ├─ styles.css
│  ├─ app.js             # 前端逻辑（三大工作台 / 计划生成 / 打卡 / 学习卡片）
│  └─ data/
│     └─ curriculum.js   # 信息系统项目管理师 24 章考纲（可自行增改）
├─ data/                 # 运行时数据（自动创建）
│  ├─ state.json         # 你的全部记录：计划、打卡、卡片、健身数据
│  └─ news-cache.json    # 资讯缓存（30 分钟）
└─ .runtime/             # 便携版 Node.js
```

## 常用操作

| 需求 | 操作 |
|---|---|
| 生成高项学习计划 | 工作台1 →「计划设置」→ 选周期 + 工作日/周末时长 →「生成学习计划」 |
| 翻看每周任务 | 工作台1 →「学习计划 · 一周一屏」用「上一周 / 本周 / 下一周」翻页 |
| 打卡 | 每行任务左侧方框；或右上角「今日打卡」写学习时长与心得 |
| 跳转学习资源 | 任务行下的 B站 / YouTube / 拓展链接，或「课程大纲」里按章跳转 |
| 巩固刷题 | 「巩固刷题」按钮 → 含「软考达人」小程序的打开说明与网页题库 |
| 刷新资讯 | 工作台2 右上角「🔄 刷新资讯」 |
| 按求职方向筛选 | 工作台2 →「🎯 我的求职方向」开关方向；筛选用「🎯 我的方向」 |
| 生成学习卡片 | 任意资讯「✨ 生成学习卡片」，或「从当前列表批量生成」 |
| 增删资讯源 | 工作台2 →「资讯源」，支持自定义 RSS（博客/新闻站/微信公众号精选导出） |
| 生成训练建议 | 工作台3 →「调整计划」→ 选目标（减脂塑形/塑形增肌/保持体能）/ 每周次数 / 时长 →「生成 / 更新建议」 |
| 主动打卡 | 工作台3 → 今日「练哪套」里选一套 →「完成打卡」；或点日历任意一天补记（选实际练的那套） |
| 今日吃什么 | 工作台3 →「🍽️ 今日餐饮推荐」（早餐/午餐/晚餐/加餐 + 外食口诀），可「换一换」 |
| 轻量日 | 工作台3 → 今日「🌸 今天轻量」，或点日历任意一天 →「🌸 轻量日」（低冲击有氧 + 拉伸，日历上标 🌸） |
| 备份数据 | 设置 →「导出 JSON」 |

## 自定义

- **改考纲**：编辑 `public/data/curriculum.js` 里的 `chapters`（章节、子知识点、重要度、拓展关键词），刷新页面即可。
- **加资讯源**：界面「资讯源」中添加；或改 `server.js` 顶部的 `DEFAULT_SOURCES`（支持任意 RSS / Atom 地址）。
- **改每天时长**：工作台1「计划设置」（默认 120 分钟）与设置页。

## 说明与边界

- 资讯来自各站公开 RSS，个别站点可能因网络原因偶发不可用（界面会列出不可达的源，可忽略或停用）。
- 微信小程序（如「软考达人」）无法从浏览器直接跳转，界面提供搜索名称与打开步骤。
- 资讯「学习卡片」的内容由关键词 + 知识模板自动生成，属于启发式学习提示，非专业结论，仅供入门参考。
